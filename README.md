## 🌟 Overview

**Auréa** is a modern, responsive flagship electronics storefront showcasing flagship smartphones (iPhone 16 Pro, Galaxy S25 Ultra, Pixel 9 Pro, OnePlus 13, Xiaomi 15 Ultra). Built with an editorial dark/light luxury design language, smooth fluid animations, and real-time client-side commerce state.

### ✨ Key Features
- **Interactive Phone Comparison Matrix**: Compare up to 4 flagship devices side-by-side across processors, display refresh rates, camera optics, battery size, and pricing.
- **Dynamic Filtering & Search**: Instant filter by brand (Apple, Samsung, Google, OnePlus), storage capacity, camera specs, and price ranges.
- **Persistent Shopping Cart & Wishlist**: LocalStorage-synced cart with coupon discount codes, EMI options, and real-time total calculation.
- **Fluid Micro-Interactions**: Page transitions, product hover tilt, and sheet overlays powered by Framer Motion.
- **Responsive Across Viewports**: Optimized for mobile screens, tablets, and wide desktop displays.

---

## 🛠 Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router v7 (`HashRouter` for static host reliability)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Badal-kumar98/aurea-smartphones.git

# Navigate into folder
cd aurea-smartphones

# Install dependencies
npm install

# Run dev server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
